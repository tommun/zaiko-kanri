# 武田塾 芦屋校 備品管理システム

教室で使用するコピー用紙や文房具などの備品在庫を管理し、発注漏れを防ぐためのWebアプリケーションです。

## 概要と主な機能
スマートフォンやPCのブラウザからアクセスし、直感的な操作で在庫の増減を記録できます。

* **在庫の増減:** 「使う(-1)」ボタンで簡単消費、「追加...」から任意の個数を補充
* **購入リンク管理:** 備品ごとにAmazonやアスクルなどの購入URLを登録・編集可能
* **品目の追加と削除:** 右下の「＋」ボタンから新規登録、不要な備品は個別削除
* **Discord自動通知:** 在庫が「1」になった瞬間、担当役職へ購入リンクと管理画面URL付きのアラートを送信

## システム構成
維持費をかけず、保守がしやすいように以下のツールを連携させて構築しています。

* **フロントエンド:** HTML / CSS / Vanilla JS (GitHub Pagesにて公開)
* **バックエンドAPI:** Google Apps Script (GAS)
* **データベース:** Google スプレッドシート
* **通知機能:** Discord Webhook

## 使い方・メンテナンス手順
1. **日常の利用:** [管理画面(https://tommun.github.io/zaiko-kanri/)](https://tommun.github.io/zaiko-kanri/) にアクセスして在庫を操作します。
2. **備品の新規登録:** 右下の青い「＋」ボタンから追加し、カード内の「🔗 編集」から購入URLを紐付けます。
3. **GASの更新方法:** コードを修正した際は、必ずGASエディタ右上の「デプロイを管理」＞鉛筆マーク＞バージョン「新バージョン」＞「デプロイ」を実行してAPIを更新してください。
4. **Webhookの変更:** 通知先のチャンネルを変更する場合は、GAS内の `WEBHOOK_URL` を新しいものに差し替えて再デプロイします。
